# Tessera

**Tessera is an SSH, Mosh, and tmux terminal for iPad.** It connects directly
to servers you own or control — there is no Tessera backend, no account, and no
data collection.

- Source code: <https://github.com/bambouville/tessera>
- Support & bug reports: <https://github.com/bambouville/tessera/issues>
- [Privacy policy](privacy-policy)
