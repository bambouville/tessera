Interaction model. ① Waiting cards parse the agent's actual menu into tap buttons — labels come from the pane, not hardcoded, so any option set renders (primary = the agent's default). “answer with a message…” expands an input for a typed reply instead of a menu pick. ② Working cards: the input queues a message (Claude Code queues typed input while running) and ⎋ interrupt sends ESC. ③ Idle cards: input sends a fresh prompt + return. ④ The live tail above each control shows exactly what you're answering; it streams, and sends echo back into it. ⑤ Keyboard-first: ⇥ cycles cards, 1–9 answers the focused prompt, ↩ sends the focused input, ⌘↩ opens the pane. “open ↩” is now a small explicit affordance — the page itself is where you act.
