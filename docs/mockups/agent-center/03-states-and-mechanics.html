  • Stale-prompt guard: before an answer button dispatches, the pane tail is re-matched against the needle that produced the buttons. If the prompt moved on (agent proceeded, output scrolled), nothing is sent — the card refreshes and flashes “prompt changed”. No blind keystrokes into a changed screen.
  • Echo verification: every send is confirmed by watching the pane echo; a send with no echo within 2s surfaces a “didn't land — open the pane” error on the card instead of silently pretending.
  • One in flight per pane: card controls disable while a send awaits its echo; no double-fire from taps + digits.
  • Buttons are parsed from the pane's actual menu text — labels, count, and default come from the agent, never hardcoded, so new prompt styles degrade to “answer with a message…” instead of wrong buttons.

keyboard & entry points

  • ⌘⇧A — toggle Agent Center (⌘A is select-all; ⌘⇧A unclaimed by iPadOS per the reserved-chord audit; letter+⌘⇧ per capture limits).
  • ⇥ cycles cards · 1–9 answers the focused prompt · ↩ sends the focused input · ⌥↩ typed reply on a blocked card · ⌘↩ opens the pane.
  • ⌘K — agents indexed in the palette; @ prefix scopes to agents only; needs-input ranks first.
  • Sidebar “agents” row · sparkle on session rows · tab-strip sparkle — all tap-through to the pane.
  • Settings → notifications: “notify when an agent needs input” (default on), per-host override; reuses bell rate-limit tiers.

scope guards

  • Detection = the two shipped profiles (claude code, codex cli) + user-added profiles from SwipePad settings; one profile store, no second registry.
  • No remote helpers, no shell integration required, no backend — probes and sends ride existing channels only.
  • Status is inferred, never claimed: chips say what was observed (“no output 38m”), the terminal remains the source of truth — which is why every card shows the live tail it's acting on, and why unparseable prompts fall back to open-the-pane.
  • v1 still excludes: diff viewer, Watch/widgets, multi-pane broadcast. Answer, message, interrupt, jump — nothing else.
