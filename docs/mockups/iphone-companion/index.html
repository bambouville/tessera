Tessera · iPhone companion
Thumb-first terminal, not a shrunken iPad. Everything is tappable: switch tabs, connect to a host, arm Ctrl/Alt on the accessory bar, type on the mock keyboard, open Files as a nonmodal sheet, pull up the command palette, drag the SwipePad open. Built to iOS 26 (Liquid Glass) HIG: floating glass chrome, content full-bleed underneath, sheets inset from the edges.

reading the chrome

  • floating tab bar — iOS 26 pattern: glass capsule above content, icons+labels; compacts to icon+label-inline in landscape.HIG tab-bars: floats above content; minimize-on-scroll available for long host lists.
  • top pill in session — back (session keeps running) · host name is the switcher · find · files · tunnels (view-only) · disconnect (red, destructive). No transport suffix.Back ≠ disconnect: HIG keeps navigation leading, destructive actions isolated; trailing items keep 44pt targets, no … menu needed.
  • accessory bar — docks above the home indicator when the keyboard is down, rides on top of it when it’s up. ⌃/⌥ arm with accent; one-shot by default.HIG virtual-keyboards: input accessory = the sanctioned place for task controls; glass matches the keyboard.
  • SwipePad — sits just above the accessory stack in the thumb’s natural arc; puck → radial petals, double-tap → dictation pill.Bottom-corner placement keeps every petal ≤ ~90pt from the resting thumb on 375–430pt widths.
  • Files sheet — nonmodal medium-detent, inset from edges, terminal keeps running behind it; no scrim.HIG sheets: nonmodal is the Notes-format-panel pattern; iOS 26 half sheets are inset with content peeking around.
  • the switcher — top-anchored card over a dimming scrim, opened from the host name. Two-layer for tmux: a window with several panes lists each pane as its own full-screen target (iPhone has no split panes).Closest HIG pattern is search-fields — one searchable location for sessions, windows, panes, agents.
  • agent center — lives in sessions as a hosts / agents view switch; optional via settings → experimental.Phone keeps agents glanceable and actionable; deep monitoring timelines stay on iPad.
Afeature triage — what crossed to iPhone, what stayed on iPad
Surveyed every major surface of the app (Hosts, Sessions, SSH/Mosh/tmux-CC transports, Panes, Keys, KnownHosts, Files, Keyboard, SwipePad, Forwarding, AgentCenter, Navigation, Notifications, Onboarding, Settings, Security, Find). Rule applied: if a feature can be operated with one thumb in ≤3 taps without shrinking targets below 44pt, it’s in — otherwise it’s dropped or demoted to read-only status.

ported (adapted)

  • hosts + quick connectCore of a companion app. 3-col iPad grid → 2-col cards + list; quick-connect field first (most phone sessions are one-off).
  • sessions (multi-session switch)List replaces the 240pt sidebar and gains hosts / agents views. tmux windows move into the switcher as a two-layer window → panes tree: existing panes become separate full-screen targets instead of split views.
  • accessory bar (esc/⌃/⌥/arrows)More critical on iPhone than iPad — the software keyboard has no modifiers. Same chips, one-shot default.
  • SwipePad + dictationRadial approve/deny is *better* one-handed than with a trackpad; puck shrinks to 52pt, petals stay 44pt+ targets.
  • files (SFTP)Floating 340pt card → nonmodal sheet; full feature parity (browse, hidden files, send-path-to-terminal).
  • the switcher (was command palette)Phone has no ⌘K, so it opens from the host name in the top pill — one surface for sessions, tmux windows → panes, and agents. The magnifier is freed up to mean find-in-terminal.
  • agent centerSessions tab hosts / agents views; every agent one thumb away, tapping jumps into its session. Optional: settings → experimental can hide it.
  • keys + known hostsPhones are the *better* key store (Secure Enclave + Face ID); list → detail sheet. Tab gains keys / known hosts views — TOFU pinning with a real revoke path, and trusting “mercury” adds a pin live.
  • known-host trust cardTOFU verification must work on first connect from anywhere; shown as flow 6 on “mercury”.
  • find in terminalDemoted to overflow (screen too narrow for a persistent bar) but fully present.
  • settings + security (Face ID lock)Single column instead of 220pt master/detail; toggles here are wired to the live session for the demo.
  • bell / attention dotsFolded into session-row status + tab badge; no separate surface needed.

left on iPad

  • split panesTwo usable terminal columns need ~700pt; at 375–430pt each pane would be ~40 columns wide. tmux windows cover the multi-context need — and when you connect to an existing tmux session that has panes, each pane shows up as its own full-screen target in the switcher.
  • agent timelines / monitoring boardThe wide multi-agent board (parallel timelines, charts) needs iPad width; the phone keeps the actionable list in sessions → agents.
  • port-forward editor / tunnels pageMulti-field form (bind, port, target, type) is a setup task, not a thumb task. Phone shows active tunnels read-only from the top-pill ⇄ button.
  • host editor — advanced fieldsJump chains, env vars, startup snippets, terminal background stay on iPad. Phone gets a minimal sheet (name/address/user/port/transport/identity) via long-press → edit… — same sheet serves “＋ new host”.
  • hardware-keyboard shortcut mapNo hardware keyboard on iPhone; ⌘-command editor surface is meaningless. Accessory bar replaces it.
  • onboarding touriPad-first flow; phone would get its own 3-screen intro, out of mock scope.
  • theme gallery (6 themes)Stays a single settings row on phone — pick from a compact list, not a visual gallery.
  • session-restore sheetMulti-select restore UI collapses into the automatic “restore on launch” policy row in Sessions.

iOS 26 HIG applied

  • Liquid Glass — chrome floats as a separate glass layer over full-bleed content; glass never used inside the terminal content layer; monochrome glyphs, accent reserved for state (selected tab, armed modifier, focused input). materials · adopting guide
  • Tab bar — floats at bottom, 4 tabs (≤5 rule), filled-variant symbols, compact icon+label-inline form in landscape. tab-bars
  • Toolbars — ≤3 trailing items + overflow menu; symbols monochrome, no circle borders; 44×44pt minimum targets drove the 44pt pill (vs iPad’s 32pt). toolbars · accessibility
  • Sheets — nonmodal + medium detent for Files; grabber; iOS 26 inset-from-edge shape; swipe-to-dismiss supported. sheets
  • Input accessory — custom task controls above the keyboard are the sanctioned pattern; glass + keyboard layout guide. virtual-keyboards
  • Full screen — chrome minimizes into the session; restore via persistent pill; home-indicator swipe kept at one-swipe (no deferral needed — no bottom-edge gameplay gestures). going-full-screen
  • Search — no command-palette pattern exists; palette is a composed search surface (type-as-you-go, recents, single location). search-fields
  • Layout — 375–430pt portrait widths (X → 16 Plus class), Dynamic-Island safe areas (59/34pt portrait, 59/21 landscape), content full-bleed under bars. layout
